# Brief for the TAW Player session: 0.2.0, from the 0.1.0 test on Linux Mint

From the family session, 2026-10-14 (logged in TAW-Panel's docs/TRACKER.md). Read CLAUDE.md, docs/ARCHITECTURE.md, ROADMAP.md and HANDOFF.md first. Work on a feature branch; release as 0.2.0 when done.

## What passed on Linux Mint (0.1.0)

FLAC album gapless · the signal-path line under the track · seek, next, random · Space, Shift+←/→, ←/→ · dropping a folder · the family switcher (started the Equaliser).

Still to test: MP3 gapless, opening an M3U8 (the Library's Play writes one), everything on Windows.

## To build

1. **Don't start playing on open.** Opening a folder, opening files or dropping fills the list and waits. Add a Settings switch, "Start playing when I open music", off by default (`Saved` field with `#[serde(default)]`). `load(paths, play, t)` already takes `play`; today every caller passes `true`. `taw-player --play …` (the Library's Play key) always plays straight away, whatever the setting says (the user's decision).
2. **Add to the list.** Opening files today replaces the list. Keep Open folder and Open files as they are (replace), and add an **Add** key next to them that appends files or a folder to the end. Dropping while holding Shift appends too. The engine's queue needs to take appended tracks without a gap or restart. Reordering and saving (M3U8) stay in the later playlist release.
3. **dB scale on the meters.** Label the LED meters: 0, −3, −6, −12, −24, −48 dB under or beside the segments, in the display's ink. The meter is `taw_panel::hifi::meter` (24 segments, −48 to 0 dB, 2 dB a segment). Put the scale in TAW-Panel as a new function, such as `meter_scale`, so the Equaliser and Analyser can use it, released as TAW-Panel 0.4.0 (its ROADMAP). The family session builds that; move the pin when it's out, and draw a stop-gap scale here only if you get there first.
4. **Centre the meters when the spectrum is off.** In the Detailed display, with the spectrum switched off, centre the meter pair vertically in the display.
5. **Media keys and system media controls.** Play/pause, next, previous and stop from the keyboard's media keys and the desktop's sound menu, with title, artist and artwork: MPRIS on Linux (Mint's Cinnamon sound applet uses it), SMTC on Windows. `souvlaki` is the usual crate. Keep it off the output callback.
6. **Bottom corner resize.** The user reports the two bottom corners don't resize the window on Linux Mint (Cinnamon, X11). Corners and edges come from `hifi::resize_edges` in TAW-Panel, called last in the frame, so the zones should win. Find out why on a real window manager. If the cause is in TAW-Panel, fix it there, because the Library, Equaliser and Analyser use the same code.
7. **Back-to-start key** (already on the roadmap for this release, if it fits).

## Checked, no change needed

- **The meters pinning on loud tracks:** the logic is right. The meter shows the sample peak after the volume, with an instant rise and a 30 dB/s fall. The top two segments are red above −3 dBFS. Modern masters peak at −1 to 0 dBFS all the time, so the top keeps lighting. The dB scale (item 3) makes that readable. Spool's 1 dB-per-step top end with peak hold stays in the later meters release.
- **↑/↓ move the highlight without playing:** keep it. The user confirmed Enter (or a double-click) playing the highlighted track is right.
